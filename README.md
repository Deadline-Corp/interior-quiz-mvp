# Визуальный бриф — подбор интерьера (MVP)

Интерактивный демо-прототип для дизайнера интерьеров: клиент выбирает понравившиеся фото мебели и материалов галочками, на выходе — визуальный бриф. Plus демо-конструктор (Этап 2).

Единая страница (vanilla HTML/CSS/JS), картинки — локальные (AI-сгенерированы). Заглушки: отправка брифа без бэкенда.
